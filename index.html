Motivación

  • El departamento de informática tenía la necesidad de disponer de un sistema de adquisición de datos capaz de adaptarse fácilmente a diferentes contextos y aplicaciones. Las soluciones comerciales presentan múltiples limitaciones.
  • Una aplicación de particular interés era estudiar el ambiente dentro de las aulas. Con estos datos se podría optimizar el uso de las mismas y conocer su confort.
  • La calidad del ambiente interior (IEQ) impacta directamente en la salud, el confort y el rendimiento cognitivo en entornos educativos y laborales.
  • A futuro se proyecta el desarrollo de gemelos digitales.

Objetivos y funcionalidades clave

El objetivo es diseñar e implementar una plataforma IoT modular, escalable, segura y resiliente para la recolección, procesamiento y visualización en tiempo real de datos ambientales.

Protocolos de aplicación personalizados

PCBPF

Protocolo de Coordinación y Balanceo Post-Fallo. Controla el envío de mensajes respaldados cuando el Edge inicia su operación y evita ráfagas de tráfico.

PV

Protocolo de Vinculación. Formaliza el descubrimiento y registro persistente entre dispositivos.

PSCH

Protocolo de Sincronización de Configuración. Mantiene la consistencia entre la configuración local y el servidor mediante confirmaciones.

PRABS

Protocolo de Respaldo de Alertas. Permite a los Hubs saltear un nodo Edge caído y enviar alertas críticas directamente al servidor por HTTP.

Resultados

Conclusiones y próximos pasos

  • Se logró desarrollar e implementar un sistema de adquisición de datos flexible que supera las limitaciones de caja cerrada de las soluciones comerciales, cumpliendo con la necesidad inicial del departamento.
  • La plataforma es altamente reconfigurable y puede transferirse a otros dominios modificando principalmente la capa 1 (Hub).
  • Si bien la plataforma es funcional, el hardware de sensado es entry-level, por lo que los datos recolectados se deben "tomar con pinzas".
